# Rubén Elías

Irrigation Engineer (**Universidad Autónoma Chapingo**) & Software Developer.  
I work at the intersection of **applied hydrology, precision agriculture, and field software**.

---

### What I do

- **Crop water modeling & irrigation:** Implementing hydrological and evapotranspiration models (FAO-56 Penman-Monteith) adapted for regional agriculture in Mexico.
- **Geomatics & 3D data:** Processing total station and differential GPS data into interactive web GIS (Leaflet, R) and 3D point cloud viewers (Potree).
- **AgTech software:** Building offline-first and agentic tooling for farm operations (Python/FastAPI, Flutter, PostgreSQL/PostGIS).
